📚 API Documentation

Gunakan API kami untuk mengintegrasikan School Trip Archive Gallery ke aplikasi Anda. Semua endpoint mendukung berbagai metode HTTP.

Authentication Endpoints

POST /api/auth/signup

Buat Akun Baru

Daftarkan pengguna baru ke sistem.

Request Body:

{\n  "fullName": "string (required)",\n  "nickname": "string (required)",\n  "age": "number (required)",\n  "username": "string (required)",\n  "password": "string (required)",\n  "email": "string (optional)"\n}

Response:

{\n  "success": true,\n  "message": "Account created successfully",\n  "token": "jwt_token_here",\n  "user": {\n    "id": "uuid",\n    "fullName": "string",\n    "nickname": "string",\n    "username": "string"\n  }\n}
POST /api/auth/login

Login Akun

Login dengan username dan password.

Request Body:

{\n  "username": "string (required)",\n  "password": "string (required)"\n}

Response:

{\n  "success": true,\n  "message": "Login successful",\n  "token": "jwt_token_here",\n  "user": { ... }\n}
POST /api/auth/guest

Guest Mode

Masuk sebagai guest tanpa perlu login.

Response:

{\n  "success": true,\n  "message": "Guest mode activated",\n  "token": "guest_token_here",\n  "user": { "id": "guest", "isGuest": true }\n}

Upload Endpoints

POST /api/upload/file

Upload File/Image

Upload gambar atau video ke sistem.

Request (FormData):

- file: File (required)\n- fullName: string\n- description: string\n- visibility: "public" | "private"

Response:

{\n  "success": true,\n  "message": "File uploaded successfully",\n  "data": {\n    "id": "uuid",\n    "filename": "string",\n    "url": "/img/filename.jpg",\n    "uploadedAt": "ISO8601"\n  }\n}
GET /api/upload/list

Daftar Upload

Dapatkan list semua file yang telah diupload.

Response:

{\n  "success": true,\n  "count": number,\n  "data": [ ... ]\n}
PUT /api/upload/:id

Update Upload

Ubah metadata file yang telah diupload.

Request Body:

{\n  "visibility": "public" | "private",\n  "description": "string"\n}
DELETE /api/upload/:id

Hapus Upload

Hapus file yang telah diupload.

Response:

{\n  "success": true,\n  "message": "Upload deleted successfully"\n}

Gallery Endpoints

GET /api/gallery/public

Gallery Publik

Dapatkan galeri publik dengan pagination.

Query Parameters:

- page: number (default: 1)\n- limit: number (default: 10)

Response:

{\n  "success": true,\n  "pagination": { ... },\n  "data": [ ... ]\n}
GET /api/gallery/random

Random Images

Dapatkan gambar random dari galeri.

Query Parameters:

- count: number (default: 4, max: 20)
GET /api/gallery/search

Search Gallery

Cari gambar di galeri dengan berbagai filter.

Query Parameters:

- q: string (search query)\n- author: string\n- minDate: ISO8601\n- maxDate: ISO8601\n- page: number\n- limit: number
